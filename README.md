# Personal Portfolio Website

A responsive-ready, single-page portfolio website developed as the final project for the **Introduction to HTML, CSS, & JavaScript** course by IBM on Coursera.

The project demonstrates foundational front-end development skills, including HTML structure, CSS styling, JavaScript event handling, and DOM manipulation.

## Live Demo

**[View My Portfolio Website](https://khaledsharif202-prog.github.io/ibm-javascript-portfolio/)**

## Features

- **About Me:** A personal introduction and overview of my development interests.
- **Skills:** A visual display of technologies and programming skills.
- **Projects:** Examples of development projects and learning activities.
- **Recommendations:** A section displaying sample recommendations created for the course project.
- **Interactive Recommendation Form:** Visitors can add a recommendation to the page and receive a confirmation popup.
- **Navigation:** Links to different sections of the single-page website.
- **Back-to-Top Button:** A shortcut to return to the top of the page.

**Note:** Recommendations shown in this project are sample content for educational purposes. New recommendations are displayed in the browser and are not saved to a database.

## Technologies Used

- **HTML5** — Page structure and semantic elements
- **CSS3** — Styling, layout, and hover effects
- **JavaScript** — Interactive behavior and event handling
- **DOM Manipulation** — Dynamically adding recommendations and displaying popup messages
- **Git & GitHub** — Version control and source code hosting
- **GitHub Pages** — Static website deployment

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/khaledsharif202-prog/ibm-javascript-portfolio.git
   ```

2. Open the project folder.
3. Open `index.html` in a web browser.

No additional dependencies or installation steps are required.
